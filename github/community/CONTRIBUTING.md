# Contributing

Thanks for your interest in contributing to an unmango project.

- **Bugs and ideas:** open an issue first, especially before a large change, so we can agree on the approach.
- **Pull requests:** keep each one focused on a single change, and fill in the pull request template.
- **AI tools:** welcome, with disclosure. Read the [AI contribution policy](https://github.com/unmango/.github/blob/main/AI_POLICY.md) before submitting work that AI tools helped produce.

A repository may have its own `CONTRIBUTING.md` with build and test instructions. Where it does, follow it alongside this one.
