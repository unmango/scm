# s4

Planned repo: `unmango/s4`.

## Description

A simple S3-compatible server for development and tests that runs wherever you are.
A shell one-liner serves the working directory, a container serves an ephemeral volume, and a script in the browser serves browser storage.
It also ships as an Aspire integration and as an in-process library.
One core implementation builds both natively and to WebAssembly, so every runtime behaves the same.
Auth accepts any credentials by default, with SigV4 checking optional.
The AWS CLI and the JS, Go, .NET, and Python SDKs form its conformance suite.

Prior art: rclone, versitygw, and many small servers cover the shell and container cases one at a time.
Nothing found runs an S3 endpoint inside the browser.

The map of the work is [#323](https://github.com/unmango/scm/issues/323).

## Name

S3, plus one: simple S3.
`s4` is the product; S3 is the wire protocol it speaks.
